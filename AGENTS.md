# Repository instructions

## Commit messages

Use Conventional Commits with this format:

`<type>(<scope>): <description>`

Use a concise scope such as `db`, `auth`, `billing`, or `api`. Keep the description clear and action-oriented, with no trailing period. Common types include `feat`, `fix`, `refactor`, `perf`, `test`, `docs`, `build`, `ci`, `chore`, and `revert`.

Examples:

- `feat(db): initialize public schema modules`
- `refactor(db): split insight and ops revisions`
